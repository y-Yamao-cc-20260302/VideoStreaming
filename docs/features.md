# 機能一覧

動画配信サービスサイトに実装する機能の一覧。

## 全体像

- **フロント (React SPA)**: 一般ユーザー向けの動画視聴サービス
- **管理画面 (Laravel Blade)**: 運営側の動画・ユーザー・課金管理

---

## フロント機能（React SPA / `/`）

### 認証 / アカウント

| ID | 機能 | 概要 |
|---|---|---|
| F-AUTH-01 | 新規会員登録 | メールアドレス・パスワード・氏名で登録（JWT 発行） |
| F-AUTH-02 | ログイン / ログアウト | JWT による認証 |
| F-AUTH-03 | トークンリフレッシュ | アクセストークンの自動更新 |
| F-AUTH-04 | プロフィール閲覧・編集 | ニックネーム / アイコン / メール変更 |
| F-AUTH-05 | パスワード変更 | 旧パスワード確認のうえ更新 |
| F-AUTH-06 | 退会 | アカウント削除（論理削除） |

### 動画閲覧

| ID | 機能 | 概要 |
|---|---|---|
| F-VIDEO-01 | 動画一覧表示 | 新着 / 人気 / おすすめ 等のセクション表示 |
| F-VIDEO-02 | カテゴリ・ジャンル別一覧 | カテゴリ（映画 / アニメ / ドラマ等）、ジャンル（アクション / コメディ等）絞り込み |
| F-VIDEO-03 | キーワード検索 | タイトル / 出演者 / 説明文 を対象に全文検索 |
| F-VIDEO-04 | 動画詳細表示 | タイトル・あらすじ・出演者・関連動画 |
| F-VIDEO-05 | 動画再生 | プレーヤーでストリーミング再生（HLS 想定） |
| F-VIDEO-06 | 視聴履歴 | 直近視聴した動画一覧。再生位置の記録 |
| F-VIDEO-07 | 続きから再生 | 視聴中断位置から再開 |

### お気に入り / レビュー

| ID | 機能 | 概要 |
|---|---|---|
| F-FAV-01 | マイリスト登録・解除 | お気に入り動画の保存 |
| F-FAV-02 | マイリスト一覧 | 保存した動画の一覧表示 |
| F-REV-01 | レビュー投稿 | ★1〜5 + コメント |
| F-REV-02 | レビュー一覧表示 | 動画詳細画面でのレビュー閲覧 |
| F-REV-03 | レビュー編集・削除 | 自身の投稿のみ |

### サブスクリプション

| ID | 機能 | 概要 |
|---|---|---|
| F-SUB-01 | プラン一覧 | 無料 / スタンダード / プレミアム 等を表示 |
| F-SUB-02 | プラン加入・変更 | サブスクリプション開始・アップグレード / ダウングレード |
| F-SUB-03 | プラン解約 | 現プランを解約（期間終了まで視聴可） |
| F-SUB-04 | 課金履歴 | 過去の支払い履歴を確認 |

> 決済処理（Stripe 等の外部連携）は今回のスコープ外。プラン状態の管理のみ実装。

### その他

| ID | 機能 | 概要 |
|---|---|---|
| F-MISC-01 | お知らせ表示 | 運営からのお知らせ一覧 |
| F-MISC-02 | レコメンド表示 | 視聴履歴ベースの「あなたへのおすすめ」（簡易版） |

## 管理画面機能（Laravel Blade / `/admin`）

### 認証

| ID | 機能 | 概要 |
|---|---|---|
| A-AUTH-01 | 管理者ログイン / ログアウト | Laravel セッション認証 + CSRF |

### ダッシュボード

| ID | 機能 | 概要 |
|---|---|---|
| A-DASH-01 | KPI 表示 | 会員数 / 有料会員数 / 当月再生数 / 当月新規登録数 |
| A-DASH-02 | 人気動画ランキング | 直近 7 日の視聴回数上位を表示 |

### 動画管理

| ID | 機能 | 概要 |
|---|---|---|
| A-VIDEO-01 | 動画一覧 | ページネーション / フィルタ / ソート |
| A-VIDEO-02 | 動画登録 | タイトル / 説明 / サムネイル / 動画ファイル URL / カテゴリ / ジャンル / 公開状態 |
| A-VIDEO-03 | 動画編集 | 既存動画情報の更新 |
| A-VIDEO-04 | 動画削除 | 論理削除 |
| A-VIDEO-05 | 公開・非公開切替 | 公開状態のトグル |

### マスタ管理

| ID | 機能 | 概要 |
|---|---|---|
| A-MASTER-01 | カテゴリ管理 | 一覧 / 登録 / 編集 / 削除 |
| A-MASTER-02 | ジャンル管理 | 一覧 / 登録 / 編集 / 削除 |
| A-MASTER-03 | サブスクリプションプラン管理 | 一覧 / 登録 / 編集 / 価格・特典変更 |

### ユーザー管理

| ID | 機能 | 概要 |
|---|---|---|
| A-USER-01 | 会員一覧 | ページネーション / 検索（メール・氏名） |
| A-USER-02 | 会員詳細 | プロフィール / 現プラン / 視聴履歴 |
| A-USER-03 | 会員停止 / 復帰 | アカウントを停止状態に変更 |

### レビュー管理

| ID | 機能 | 概要 |
|---|---|---|
| A-REV-01 | レビュー一覧 | 動画別 / 投稿日順 |
| A-REV-02 | レビュー削除 | 不適切な投稿のモデレーション |

### お知らせ管理

| ID | 機能 | 概要 |
|---|---|---|
| A-NOTICE-01 | お知らせ CRUD | 公開期間付きで運用 |

## 機能スコープ（このサンプルでの実装範囲）

| カテゴリ | 実装する | 実装しない |
|---|---|---|
| 認証 | JWT (SPA) / セッション (管理) | SNS ログイン / 2FA |
| 動画 | メタデータ管理 / URL でのプレーヤー再生 | 動画ファイルアップロード / エンコード / CDN |
| 決済 | プラン状態管理（DB のみ） | Stripe 等の外部決済連携 |
| 視聴 | 視聴履歴 / 続きから再生（再生位置 DB 記録） | DRM / 同時視聴制御 |
| レコメンド | 視聴履歴ベースの簡易ロジック | 機械学習・パーソナライズ |
